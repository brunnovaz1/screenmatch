# Estrutura de Dados
>Podemos afirmar que um programa é composto de algoritmos e estruturas de dados, que juntos fazem com que o programa funcione como deve.
>## Array
> Também chamado de vetor, matriz ou arranjo, o array é a mais comum das estruturas e é uma lista ordenada de valores. 
 Por ser ordenada, os valores serão sempre acessados na mesma ordem a não ser que seja alguma função ou método.
